# 스튜디오 지브리 Re-Design

최신 소식, 영화 리스트, 각 영화마다 관련된 정보를 확인할 수 있는 정적 페이지.
애니메이션으로 유명한 회사답게 많은 이미지를 활용하고자 함.

### 기능

`스트리밍 서비스`, `관련 굿즈샵`으로 경로 연결

검색하면 `구글 검색`으로 이동

고정 헤더가 아니므로 `맨 위로` 버튼을 추가

사용자가 답답함을 느끼지 않도록 이미지 슬라이드 `진행 바` 를 추가
